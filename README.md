# Omni AI Workflows (`omni.winplaybox.in`)

> **Autonomous Prompt-to-Workflow Synthesis, Visual Pipeline Canvas, and Daily Automated Production Blueprints.**

Part of the **[WinPlayBox](https://winplaybox.in)** sovereign developer ecosystem.

---

## ⚡ Core Capabilities

1. **Prompt-to-Workflow Engine**:
   - Describe any business, developer, or marketing logic in plain English.
   - Omni synthesizes complete multi-step node topologies (Triggers, API Webhooks, AI Reasoning, Transformations, Storage, Alerts).
2. **Interactive Visual Canvas**:
   - Real-time SVG bezier cable routing, node parameter inspector, and live data packet animations.
3. **Multi-Platform Code Export**:
   - Export synthesized workflows directly to **n8n Workflow JSON**, **Zapier CLI Code**, **Python (LangChain / LangGraph)**, or **Node.js (Async Execution)**.
4. **Daily Automated Workflow Drops (`/blog`)**:
   - Automated daily publication of production-tested workflows covering SEO, Content Repurposing, Lead Enrichment, Price Monitoring, and Hybrid RAG.
5. **Ecosystem & Legal Compliance**:
   - Fully compliant with **Terms of Service** (`/terms.html`) and **Privacy Policy** (`/privacy.html`).
   - Integrated with WinPlayBox Hub, Tutorials Academy, Tech Blog, and OVD Media Transcoder.

## 🚀 Running Locally

```bash
# Serve statically with any web server:
npx serve . -l 3000
# Or with Python:
python -m http.server 3000
```

To run the automated daily workflow generator:
```bash
npm run generate-workflow
```
